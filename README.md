
# AI-Based Iris Presentation Attack Detection

A Streamlit research demonstration using a trained ResNet18 model to classify iris images as bona fide or printed presentation attacks.

## Features

- Upload iris images
- Webcam image capture
- OpenCV eye detection
- Eye-region cropping
- ResNet18-based classification
- Bona fide and attack confidence scores

## Technology

- Python
- PyTorch
- ResNet18
- OpenCV
- Streamlit

## Disclaimer

This application is an academic research demonstration.
It is not a production biometric authentication system.
Predictions do not establish identity or liveness.
